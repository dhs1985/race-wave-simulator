This is an event flow simulator designed to visualize runner density and spacing along a race course. To set up a map, all you need to do is download a GPX track from your Strava activities and upload it right into the app. It renders the course on a retro canvas so you can easily track how groups of runners move and spread out across the route.

For the runner data, you can upload either a standard CSV file or an Excel spreadsheet using the example template structure. Right now, individual runner start times inside the data files are still a work-in-progress, so you just need two core columns to get things moving: Race No and Net Time. If you are using a CSV, just format the net times as plain text like h:mm:ss, and if you are using Excel, the app will automatically handle native Excel time decimals.

Once your GPX track and data file are attached, you can set your global event start time using the time-of-day simulation clock and hit play. It’s built to handle multiple events or waves on a single screen, giving you a quick and clear way to test race schedules and spot potential traffic bottlenecks.
